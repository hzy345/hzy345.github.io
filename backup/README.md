# 个人网站

一个简洁的个人网站模板，使用纯 HTML、CSS 和 JavaScript 构建。

## 功能特点

- 🎨 现代简洁的设计
- 📱 响应式布局，支持移动端
- ✨ 平滑滚动和动画效果
- 🚀 纯静态页面，加载速度快

## 预览

访问网站：https://your-username.github.io

## 使用方法

1. 克隆仓库
   ```bash
   git clone https://github.com/your-username/your-username.github.io.git
   ```

2. 修改内容
   - 编辑 `index.html` 修改页面内容
   - 编辑 `style.css` 修改样式
   - 编辑 `script.js` 修改交互效果

3. 部署到 GitHub Pages
   ```bash
   git add .
   git commit -m "更新网站"
   git push origin main
   ```

## 自定义

- 修改 `index.html` 中的个人信息
- 修改 `style.css` 中的颜色和样式
- 添加新的 section 到 HTML 中

## 技术栈

- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (ES6+)
